# Fart Gym

Sitio web estático para Fart Gym con secciones de inicio, planes, galería, tienda y contacto.

## Estructura

- HTML: index.html
- CSS: CSS/style.css
- JavaScript: JS/
- Imágenes: IMG/
- Videos: VID/

## Cómo abrirlo

Abre index.html directamente en tu navegador o sirve la carpeta con un servidor local.
